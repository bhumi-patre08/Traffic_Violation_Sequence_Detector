📖 How to Use the DFA Traffic Simulator

Automaton Objective

The DFA detects when a driver commits a specific sequence of traffic violations consecutively without resetting.

Default Violation Sequence:

  • Step 1 (R): Driver runs a Red Light → State moves to q1
  • Step 2 (S): Driver exceeds speed limit → State moves to q2
  • Step 3 (H): Driver fails to wear a helmet → State moves to q3 (ACCEPT State)

Key Features:

  • Run Target Violation: Automatically triggers the sequence R → S → H to view the full visual simulation.
  • Manual Triggers: Test individual events (R, S, H, or wrong events X) to observe state transitions and graph node illumination.
  • Pattern Switcher: Toggle between different violation patterns (e.g. Stop Sign → Illegal U-Turn).
  • Batch Evaluator: Enter any custom sequence of symbols to test DFA acceptance instantly.
